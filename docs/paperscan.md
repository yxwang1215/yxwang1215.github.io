# PaperScan / 图片转 PDF 与扫描增强

位置：`/tools/png-to-pdf/` 为扫描增强工具。`/tools/` 保留已有基础 PNG 转 PDF 页面，并增加 PaperScan 入口。

## 功能

浏览器本地批量导入 PNG、JPEG、WebP、BMP、GIF（首帧），以及浏览器可解码的 AVIF。支持拖放、粘贴、文件选择和拍照文件选择器；拍照行为取决于设备与浏览器。

页面独立保存增强、旋转与矩形裁剪设置。预设为原色、清晰彩色、灰度、黑白扫描；亮度、对比度、文字锐化、纸张去灰与黑白阈值均可调。可将增强参数应用到所有页面，但不覆盖各页裁剪与旋转。支持卡片拖动排序、前移/后移按钮、删除、原图/增强/滑动对比。

导出：合并 PDF，单页 PNG/JPG/WebP，全部页面 PNG/JPG/WebP ZIP。PDF 提供 A4、A5、Letter、适应图片，以及方向、页边距和 JPEG/无损编码。适应图片按 300 dpi 映射物理纸张大小；不会添加 OCR 层。PNG 与无损 PDF 不应用有损质量参数。所有透明像素叠加白底；原文件不会被修改。

## 实现与边界

无运行时第三方依赖、外部 CDN、服务器接口、遥测或持久化图片存储。独立 HTML 不继承主页的统计脚本。CSP 限制脚本/Worker 为同源，禁止网络连接、对象与表单提交。下载通过本地 Blob 创建；再次导出时释放旧 Blob，清空全部页面会移除上次导出链接及其 Blob。

`core.mjs`：基于网格 85% 亮度分位数及双线性插值的局部纸张背景估计、亮度归一化、对比度、限制正向光晕的 unsharp masking、自适应局部二值化。像素操作在 `worker.mjs` 内执行，Worker 不可用时退回主线程。预览最多 1100 px 长边；导出重新解码源图，不使用预览截图。

PDF 为纯图像 PDF 1.4：DeviceRGB 图像 XObject + DCTDecode 或 FlateDecode，字节计数 xref，独立阅读器可解析。ZIP 为 STORE 格式，保留图像已有压缩，含 UTF-8 文件名标志和 CRC32；按页面顺序加数字前缀避免重名。

资源限制：50 页、30 MiB/文件、150 MiB 导入总量、4000 万像素解码后检查、1200 万像素处理上限、150 MiB 编码结果上限。分辨率选项限制最长边，不做无意义放大。超大图片在解码阶段仍可能消耗较多内存，手机建议降低分辨率和分批处理。取消会等待当前页面的处理完成，然后停止；不会保存部分 PDF/ZIP。

HEIC、TIFF、PDF 导入、OCR、自动透视矫正、自动轮廓识别和 AI 失焦恢复不在本版范围内。锐化无法恢复源文件中不存在的细节。纸张去灰可能改变彩色图表，预览后再导出。不是扫描全能王的官方产品或复刻算法。

## 运行

无构建步骤，直接作为 Jekyll 静态文件发布。复用已有主页导航 `Tools → /tools/`；保留基础工具及其资源，只在基础工具页面增加增强版入口。

本地常规预览：在仓库根目录运行 `python -m http.server 8000`，打开 `http://localhost:8000/tools/png-to-pdf/`。不要通过 `file://` 打开 ES module 页面。

核心测试：`node --test tests/scanner-core.test.mjs`。

浏览器测试：环境需 Python 的 `playwright`、`Pillow`、`PyMuPDF` 与 Chromium；运行 `python tests/scanner-e2e.py`。可设置 `CHROMIUM_PATH` 与 `SCANNER_QA_OUTPUT`。

此交付环境的浏览器管理策略禁止 URL 导航，因此浏览器测试将本地 HTML/CSS/相同 JS 源码注入空白文档，并将 Worker 模块内容打包为本地 Blob Worker。没有改动浏览器策略。它验证图像处理、交互、实际导出文件和响应式布局，但不等于在生产 URL 测试了 CSP、模块 URL 解析、Safari/iOS 或真实手机摄像头。生产资源与部署状态另外核查。

## 验证记录

14 项 Node 核心测试通过；六种图片格式导入，坏文件隔离，四个像素预设，六页 JPEG/无损 PDF，三个单图导出格式，三个 ZIP 格式与 CRC，Unicode 文件名，旋转/裁剪/重置，顺序调整，前后对比，取消导出，EXIF 方向、透明白底和清空确认均经过测试。宽度 1440、1024、768、390、320 px 无横向溢出。生成的 PDF 已使用 PyMuPDF 解析并渲染检查。此记录不声称所有浏览器兼容。
