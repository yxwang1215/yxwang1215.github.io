    01 / PRIVATE BY DESIGN

    你的文件，只属于你

    图片与 PDF 仅在当前浏览器内存中处理，不上传、不记录文件内容。刷新或关闭页面后，未保存的任务会清除。网页本身仍由 GitHub Pages 提供。

    02 / PIXELS, NOT PROMISES

    为清晰的文档而做

    「清晰优先」保留浏览器解码后的 8-bit 像素与透明度，不保留原始 PNG 元数据或 16-bit 色深。生成的是图片 PDF，不含 OCR 或可编辑文字。

    03 / SMALL & CONSIDERED

    轻一点，也稳一点

    每张图片最多 1600 万像素，单边不超过 16384 px；暂不支持动态 PNG。手机内存有限，建议少量分批转换。工具没有外部脚本、字体或广告。
