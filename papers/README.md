# Paper project pages

`papers/` is the first-level home for research paper project pages on the personal site.

- `index.html` is the paper-project directory page.
- `lp-sft/` contains the LP-SFT project page and its project-specific notes.
- `assets/` stores paper figures and lightweight PDF artifacts shared by the project pages.

Each new paper should receive its own second-level directory and a link from `index.html`.
