# SRP-SFT project page

`papers/srp-sft/` contains the project page for **Beyond Distribution Matching: Selective Margin Preservation for Supervised Fine-Tuning** (arXiv:2610.19685v1).

- `index.html` is the oral-style paper page with the author block, teaser figure, method overview, result chart, and mechanism diagnostics.
- Shared styling lives in `../../assets/css/paper-project.css`.
- Paper figures and the source PDF live in `../assets/`.

The legacy `/papers/lp-sft/` URL redirects here because this is the paper represented by the requested PDF.
