# glance-etd/

This directory contains the Glance-ETD project page for “Glance, then Select: Evidence-Tempered Visual Token Selection for Extremely Compressed Multimodal LLMs.” Its `index.html` is the Jekyll source for `/papers/glance-etd/`; shared paper figures live in the sibling `papers/assets/` directory; the published manuscript is linked from [arXiv](https://arxiv.org/abs/2611.20006).
